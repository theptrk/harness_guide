# Infinite Teammates

A tutorial that builds an agent from first principles, level by level, up to a Grokbot-like system.

## Writing

Write it the way you'd explain it to someone sitting next to you. Say the thing, then stop.

No metaphors. Name the actual mechanism. If a phrase can't be checked against the code — "growing up", "put X between Y and Z", "the part worth copying" — it's decoration.

Most bad writing here is connective tissue: the sentence written to bridge two concrete statements. Bridges have no facts in them, so nothing constrains the wording and metaphor fills the slot. Two concrete sentences next to each other usually need no bridge. Delete it instead of writing it.

Also watch for: every item in a list having the same rhetorical shape, clever headlines that don't make sense until you read the body, and numbers picked because the sentence wanted a number.
